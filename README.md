# بطاقات التواصل الرقمية — مطبعة نزار الفن للدعاية والإعلان والطباعة

بطاقات NFC/رقمية (HTML ثابت) — تصميم CtrlZ.

- `/`         بطاقة المطبعة (رقمَي محمود أبو حسن + موفق أبو البراء)
- `/mahmoud`  محمود أبو حسن — مدير التسويق
- `/moafaq`   موفق أبو البراء — المدير التنفيذي

كل بطاقة: حفظ جهة الاتصال (vCard) · واتساب · اتصال · الموقع على الخريطة · تقييم قوقل.
